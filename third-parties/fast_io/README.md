# fast_io (vendored / modified)

This directory contains the fast_io library payload imported from the local
`fast_io_new` repository at commit
`5a51c43e78ba700b87766b5c6a6f91746304a104` on 2026-09-05.

The imported payload consists of `include/`, `share/`, `.clang-format`, and
`license.txt`. Upstream build outputs, tests, benchmarks, Git metadata, and local
experimental files are not part of this vendored snapshot.

`license.txt` is copied from that exact source revision and contains its MIT
license and copyright notices. This snapshot replaces the previous vendored
version; its provenance and license file must be reviewed together rather than
inferred from the older snapshot's README.

This is a modified fast_io distribution, not an official upstream mirror.
Subsequent uwvm integration fixes are recorded in separate commits so that the
unmodified import can be identified and reproduced.
