# Actual checkpoint host-operation admission candidate

This candidate adds a private producer for the existing host gate. It is source-only: the new private leaves are present, but the runtime aggregation and thread-method changes are still proposed in the accompanying source packet. No native test, full checkpoint save/restore, or protected-asset issuer has been qualified.

The configured full-LLVM checkpoint profile alone creates an immutable retained gate/profile/control/epoch owner. A cold external execution entry obtains its actual generation lease and runtime depth first, then a counted setup operation before compilation caches, native targets or guest participant enrollment. Full and raw entry release that setup count only after the existing producer has enrolled the actual participant. Prepare-only code compilation keeps its operation through return. Every scope dies before its separate execution lease; the gate's shared control block never substitutes for a VM lifetime pin.

Checkpoint-selected import/raw-target bridges use `runtime_checkpoint_host_bridge::foreign_operation_scope` only for actual foreign native leaves. A defined cross-module Wasm leaf does not acquire a host count or lose its caller identity. Native normal return and C++ unwinding destroy the real scoped operation. Typed-tail dispatch does not infer authority from a retired caller/top frame. The effect owner separately marks unadapted imports nonreplayable; this gate does not create replay adapters.

A callback that reenters the public raw API still executes with the existing guest semantics. Its genuine nested entry marks the gate permanently untracked, while the outer native operation remains counted. A manager must immediately decline busy/untracked cases; it cannot wait for a parked guest's enclosing native continuation to return. The old void raw ABI explicitly terminates on refused admission before dispatch instead of silently continuing a target.

Configuration has a real race otherwise: an entry could see recording disabled immediately before another host installs recording. `execution_domain::with_quiescent_configuration` excludes that race using maintenance `try_lock`, admission lock, and a short actual lifetime check for active zero/nonstopping. The private current lifetime cannot be externally entered. The lifetime lock ends before publication; admission stays closed to new entry through the bounded internal setter. Reset/stop share maintenance. The callback cannot compile, call observers, enter/reset/drain this domain or destroy externally owned contexts. Replaced owners are moved out and destroyed after locks release. Existing `try_enter`, generated IR, polling, and linear-memory accesses are unchanged; ordinary external entry adds one cold enabled-load and empty local-scope cleanup only.

The future coherent manager sequence remains: actual generation/source lease, pause and wait all real guest participants, ONE stopped-domain callback, nonwaiting gate close, then canonical publication/cohort and complete guest/native-asset census. Nothing in these leaves implements that future private issuer. A closed gate and diagnostic count zero are not world-stop credentials. Escaped preload views, native plugins/opaque imported memories, untracked continuations and unknown guest descriptors remain unavailable until a real census/retained-owner system proves them; these new leaves do not retract raw pointers or authorize publish/restore.

Source candidates preserve ordinary/ROS differences. The actual standalone unit exercises live execution-domain leases, an entry/configure race, and concurrent real reset; it has no runtime/private bridge substitute. Remote acceptance must build it under the sole keeper's existing cgroup, then build fresh actual runtime and consumers from the reviewed combined effect/gate cut. Actual product tests must cover real setup-before-park, known foreign normal/EH exit, defined Wasm import, typed host tail, native callback reentry (busy/untracked), refusal before target side effects, reset/stop retirement, and ordinary generated IR/assembly equivalence. Component tests do not prove those product paths.

One separately owned experimental path is still outside the proposed counted entry: with `UWVM_EXPERIMENTAL_EXCEPTION_SOURCE_RETENTION=1`, `prepare_actual_source_exception_publication()` can take its own real generation lease and compile before `runtime_execution_entry_scope` is constructed. The helper already declines a retained debug control later, but needs that same decline before its initial compile, or its own real setup admission. This source packet records the pending coverage; it does not edit the exception-publisher owner's leaf or claim a completed coherent checkpoint issuer.
