# Native XMM/x87 register values: narrow source proposal, no runtime qualification

The real Linux x86-64 TRAP_TRACE/TRAP_PERF handler copies only named XMM0..15, 80-bit x87 st0..7, fcw/fsw/abridged ftw/fop/mxcsr/mxcsr_mask values from the complete libc-typed 512-byte FXSAVE prefix. The original actual trap, private session, typed Wasm owner range, participant/domain ticket, current publication and execution-lease checks remain authoritative. No signal-context pointer or captured native address reaches the public reply. x87 instruction/data addresses, padding and reserved state are excluded. Null or a non-512-byte SDK base leaves floating state unavailable. No new permission, arbitrary process/native memory access, register write or VM stepping is added.

`info registers` retains its original GPR-only output. `info registers $xmm0`, `info registers st(0)`, `info registers mxcsr` select immutable values at the same real stop. `info all-registers` (also `info registers all`) includes both GPR and floating values. Existing DAP debugConsole/evaluate routing uses that same parser/controller/formatter; this does not claim a new DAP register variables scope. Byte values use bounded FastIO full-width hexadecimal formatting, independent of host endian. The existing .cppm whole-header exports cover the new types/functions; no new production file or module dependency is introduced.

This first narrow cut does not provide YMM/ZMM, register writes or other-platform floating adapters. Existing Windows/macOS/AArch64 adapters leave the new owned value state unavailable; adding that data field does not enable an unqualified backend. NI remains under its existing exact-1 product gate/default OFF. Only native-stop capture/copy/display changes: no generated memory access, ordinary interpreter/JIT instruction or non-debug observer path changes.

`native_fp_registers_model.cc` is explicitly pure HOST owned DATA/typed SDK-layout checking, never a minted guest stop or trap. `debug_native_fp_registers_runtime.cc` independently uses the actual owning loader, producer/runtime/controller and genuine emitted code. It preserves the R5 boundary search/prefix/all-GPR/control refusal oracle, additionally compares complete floating state under rejected/stale requests and checks selection, all-registers/default compatibility and refusal of excluded/unqualified registers. The separately ROOT-approved original prefix WAT is required for all original coverage counters; no fake PC, MC gate weakening, controlled mapping or expected label is injected.
