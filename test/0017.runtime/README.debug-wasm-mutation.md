# Current typed Wasm global/table mutation

This private source proposal adds management-only `set wasm` commands to LLVM JIT full. It is not compiled, executed, officially WAT-validated, or accepted yet. The DATA grammar and DAP cache tests cannot prove the native transaction. Its six runtime integration before images are the exact complete-instance census82 R2 AFTER images; apply only after ROOT composes the actual feature-policy successor and reviews each narrow delta. It must not overwrite newer native step, retirement, source ownership, or cache code.

A command identifies one original module/global or table/element and one actual parked participant. Numeric sources use explicit i32/i64/f32/f64/v128 raw bits; integer/float wire bits use FastIO LE, and v128 keeps byte lanes. Reference sources are null, bounded i31 bits, an actual registered function index, or one original current local/operand/saved parameter/global/table root followed by original member indices. There is no host address, dense reply-object identifier, arbitrary expression evaluation, or native memory write. CLI paths are bounded to16 edges; the management API can carry a bounded4096-edge original path, but DATA labels never add write permission.

```
set wasm global MODULE GLOBAL THREAD bits i32 ffffffff
set wasm global MODULE GLOBAL THREAD bits f64 7ff0000000000001
set wasm global MODULE GLOBAL THREAD bits v128 0706050403020100 0f0e0d0c0b0a0908
set wasm table MODULE TABLE ELEMENT THREAD function SOURCE_MODULE FUNCTION
set wasm global MODULE GLOBAL THREAD from globals SOURCE_MODULE GLOBAL path FIELD
set wasm global MODULE GLOBAL THREAD from locals FRAME LOCAL
```

The controller obtains its real current complete roster, resolves opaque captures through the private native producer, and calls the genuine coherent manager once. The manager reacquires a true execution lease, ONE complete parked cohort, the actual closed tracked-host gate, real N exclusion/root proof, current immutable source/member declarations, current compiled generation, and publication. A previous VIEW is not a token. Each resource alias hop must be an actual owned record before its union is read. Const globals, incomplete/stale cohorts, unavailable initialized sources, wrong canonical recursive reference types, and out-of-range table64 indices leave the target slot unchanged.

The private mutator verifies both canonical destination GC roots identities (get and control block), proves a reference in an actual local source registry, and retains it before committing one typed slot. For foreign compact aggregates, generic matcher/retain would reenter shared admission while the same N exclusion is held; this implementation uses actual local-token membership/canonical subtype and the already-proven destination roots' nonwaiting source-owner hold instead. Exn and Wasm-created extern registry ownership are checked before token data is read, and their first registry lock is released before the existing precisely proven recipient retention. An opaque host extern can only reassign an authentic rooted carrier without reading it or granting host rights. Recipient lease/root bookkeeping may remain after a refusal; only the target value is guaranteed unchanged.

Tables are updated once under the existing debug-full table mutex. The actual typed slot is the GC root; holding an arena/store alone is not a root. Global numeric unions copy the exact4/8/16-byte declared carrier without evaluating floating-point bits. A final real current-scope check precedes the single slot write. Success retires the controller's stop/source/path DATA labels while retaining its genuine cooperative ticket/captures. DAP console `evaluate(context=repl)` can issue the same strict command and invalidates all detached display labels before sending; watch/hover remains read-only.

Core invariants follow the official [Core3 variable validation](https://webassembly.github.io/spec/core/valid/instructions.html#variable-instructions), [global execution](https://webassembly.github.io/spec/core/exec/instructions.html#variable-instructions), [table validation](https://webassembly.github.io/spec/core/valid/instructions.html#table-instructions), and [table execution](https://webassembly.github.io/spec/core/exec/instructions.html#table-instructions): immutable globals cannot be assigned, assigned values must match the destination's actual type, and element indices are checked against the current table extent. A debugger write still needs its separate trusted native transaction; the specification does not issue this permission.

Native qualification must run under the original Linux64GiB keeper, first standalone header/DATA then fresh product TUs. Run both products with instruction and unwind. The modern real two-module/two-participant fixture allocates a compact numeric struct, recursive struct/array, exn, extern wrapper, packed field, typed function references, and table64. It tests canonical foreign-store retention, original current locals/operands/path sources, the actual hidden nondefaultable if-entry saved parameter, every numeric carrier, alias resolution, immutable/type/range failures, incomplete/forged captures, competing N readers, and stale resume denial. The resumed guest actually uses the changed typed global and table function references and dereferences the foreign compact struct. A scheduler miss is never a positive episode; its guest assertions are armed only after the real whole mutation batch. Actual big-endian DATA runs require `--require-big` on a genuine QEMU target, not a byte-swap simulation.

This proposal does not claim whole-instance restore, GC-field mutation, custom typed DAP setVariable, WASIp1 external-resource recovery, or integration into deterministic replay's external event log. Successful management writes need a new recording origin or authenticated mutation-event recording before old deterministic recordings can be reused.
