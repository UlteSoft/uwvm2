The paired host fixture exercises actual full LLVM JIT NI through the public
controller under instruction and unwind stack policies. It runs a Core3 module
with GC roots, memory64 load/store, return_call and try_table/cross-function EH.
A bounded loop establishes genuine physical stops, then attempts SI before NI.
Returning NI is counted only after SI refuses at the same retained trap and NI
returns to the authenticated original Wasm caller. Missing native continuation
coverage, kernel denial, timeout or exit77 cannot produce PASS.

Public bridge rows intentionally contain no instruction bytes, text or branch
target. The fixture verifies that clearing and the hidden FP/SP/flags mask. It
never decodes hidden VM scaffolding or reads a native stack address. The actual
runtime issuer alone proves the sealed caller fallthrough, private kernel GPRs,
physical activation and publication under its single resume transaction. NI
runs an opaque host/VM callee with TF off; its result gives no callee code,
register, stack or memory capability. Typed callee authority remains separate.

Each returned NI must have a fresh authentic native stop in the same owner,
module/function, generation and runtime epoch. An old-stop NI must preserve that
new stop. NI abandonment must produce a genuine caller cooperative Wasm pause
with cleared native instruction/from/to fields and reject its old physical stop.
The return scenario requires two real continuations; the exception workload
requires one continuation and one abandonment. Successful guest completion must
produce106 or4294967294 respectively. This proves eventual exception execution,
not the exact cause of an individual abandonment. Hidden call operand classes
are not claimed by public output.

Actual reset disables the owned events, waits for the selected worker ACK and
physical join, then checks observer/controller retirement. A successful trap
alone is not permission to close retained FastIO descriptors or code owners.
Event/target/capacity refusal must retain the original stop and public register
copy; it never substitutes for the required positive NI coverage.

The keeper-only runner checks the original Linux64GiB cgroup, binary identity
and a reviewed fresh build/link record. It parses and validates the WAT with
wasm-tools --features=wasm3 and executes instruction/unwind x return/exception
per product. Children have a75s process timeout, 2GiB address-space limit and
16MiB output limit, with no core dump. Source, tool, Wasm, binary and build-record
hashes are retained and rechecked. Build provenance must independently qualify
the actual production runtime/host source, SDK and static archive closure.

Exact EH cause, six exact VM-entry families, recursion, peer loss, two-thread,
interrupt, replacement/restore and all cancellation races need separate real
witnesses. Native finish/caller CFI and non-Linux continuations remain unfinished.
This fixture does not claim full GDB/LLDB parity or a complete platform matrix.
