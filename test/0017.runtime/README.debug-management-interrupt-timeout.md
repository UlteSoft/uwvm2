# Management interrupt timeout retention (source proposal)

This narrow delta is based on exact NI+management R4 controller SHA 8975dd62bf5e3b50e2ba4dd0d40366ec305beb7c2ea59ca44d5eae62f9af86b2. It does not replace a live controller wholesale. ROOT alone publishes source.

A synchronous execute-stack observation latches the first trusted host interruption. The source/Wasm step and explicit pause timeout paths cancel automatic step policy but retain or actually request the cooperative pause after observed Ctrl+C. They reply timed-out/rejected and obtain display execution state from actual domain capture. They cannot report stopped merely from the flag, deadline or public label. Without Ctrl+C the existing timeout resume policy remains. Native released-phase ACK waits are unchanged and remain uncancellable; native failure must retain all actual borrowers/owners until drain.

`debug_management_interrupt_observation.cc` tests the real synchronous transient flag and nested borrowed observation. `debug_management_interrupt_timeout.cc` uses the actual controller and cooperative domain with a genuine admitted but uncooperative HOST participant. It verifies ordinary timeout resume, observed-interrupt timeout retention, no fake stopped label, actual participant retirement/capture and explicit later continue. It does not create JIT frames or qualify source steps/native NI. Native compile/run count for this proposal is zero.

Keeper finite test request: run both components against the exact new cut inside the existing 64 GiB cgroup. Then test the full source/Wasm/NI paths in instruction/unwind policies: Ctrl+C while blocked in a legitimate long host call, deadline before all participants can park, flag consumed by its input adapter, and later real safe-point stop. Require timeout/error plus actual pending admission (no silent continue), no fake current stopped label, and later explicit continue. Test native cancel colliding with handler trapped CAS/observer mutex/event-disable failure; released ACK cannot be canceled and failed drain must retain ownership. Source step tests need real DWARF activation metadata and must not fabricate it. Existing no-interrupt timeout results must remain unchanged.
