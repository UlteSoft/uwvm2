## R3 actual runtime T2 consumption (private, source only)

This derivative adds the real tiered callback replacement: one exact private
plan/source/runtime generation/actual immutable emission policy/target/feature
owner -> ALL bounded retained fragments -> existing real full optimizer/engine
-> ALL original typed/raw/core/OSR symbol resolution -> owned actual loaded entry
ranges -> original physical wrapper suppression -> original cold T2 publication.
Runtime now marks real tiered admission as tiered, keeping only that mode's exact
metadata. No plain-LLVM, ROS, debug/full or checkpoint mode is routed into T2.
No unavailable fragment, allocation failure or quota condition may cause another
Wasm body walk. Legal native-unavailable optimization retains original T0/T1.

Both genuine claimed T1 groups and ALL factory-owned T2 IR share one private
retained unwind-import IR selector. T2 does not fake compiling function/CU states;
it instead requires actual same linked callee definitions. Only the selected
static same-module import alternative is changed. Table/ref/foreign imports
retain original mutable routing, canonical matching and lease lifetime.

Native unwind T1 IR can contain hidden-argument cores and OSR wrappers. R3 bounds
a best-effort nothrow integer alias allocation to 65536 entries, resolves every
actual symbol in the same engine before adoption, and requires the same private
listener's exact loaded function entry confined to actual relocated text. After
ALL symbols/actual code-owner adoption/range commit, it records core/OSR aliases
with the existing T1 wrapper suppression before T2 READY. This diagnostic integer
proof grants no arbitrary-PC/native memory/debugger permission. Instruction T2
and ordinary full allocate no alias rows: their optimizer may inline away cores,
and logical instruction frames remain authoritative. Actual symbol/range failure
declines T2; the original admitted T0/T1 code owners remain live.

The real runtime already binds full/partition cache identity to complete
preoptimization module bitcode AFTER actual target attributes, not just raw Wasm.
This exact retained IR shape therefore cannot use an old direct-translation
module's key. No additional redundant whole-plan SHA or cache claim is invented.
Actual ordinary runtime lazy target cells are ALWAYS Acquire/Release atomic, so
non-atomic warm-target constant baking is only an external compiler API optional
configuration, not an observed default-runtime regression. The old T2 direct
shape still differs from retained T1 slots/OSR wrappers; no performance parity or
improvement is claimed. Actual checked-IR specialization and P-core A/B remain
