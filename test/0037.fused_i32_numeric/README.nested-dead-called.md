This does not alter the immutable/applied i32 R4 source package. The _start function contains a genuine branch followed by logical nested block/loop frames; it also calls $nested, whose result block branches with its actual argument into its continuation. Both dead loop bodies contain all18 i32 opcodes plus an unreachable execution sentinel. The live path uses struct.new and a nondefaultable typed GC local, calls the child with 42 and traps unless the result is 42.

This closes the earlier fixture reachability gap: the previous nested body belonged to an unused function with an empty _start, so lazy translation was not guaranteed to inspect it. Successful runtime execution must not be described as executing those numeric instructions, proving fused translation provenance or native IR/object absence.
