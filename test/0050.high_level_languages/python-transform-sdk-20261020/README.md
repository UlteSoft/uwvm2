## Implemented interfaces

The complete immutable dataclass contains sequence, seconds, nanoseconds,
parent/child frames, XYZ translation and XYZW quaternion. The explicit backend
codec checks exact integer profiles, bounded canonical ASCII frame grammar,
distinct frames, finite f64 components and squared quaternion norm before
exposing bytes/values. It preserves accepted floating-point bits, rejects
forged lengths/truncation/trailing bytes and performs no normalization or
identity fallback. Both backends currently use the Host's nonnegative
signed-i32 seconds profile; ROS1 preserves u32 sequence, ROS2 requires zero.

`TransformBuffer.lookup` sends one u64 timestamp through an already opened
alias whose grant fixes the frame pair. Required-capacity, timeout and
disconnect outcomes are preserved without hidden resize or replay.
`TransformBroadcaster.broadcast` encodes first, invokes once with output
capacity 0 and returns the original ABI Result. A wrapper or codec creates no
grant. Host frame/type/bound/quota checks remain authoritative.

The Guest embedding adds explicit `ROSWASM_PYTHON_ROS_BRIDGE=0/1`, default 1.
The pure profile omits C ROS registration/bridge linkage; the selected ROS
profiles retain the existing exact 38/43 numeric imports. This is separate from
Host debugger language switches, which remain default-ON for all fifteen
languages. Keeping all adapters enabled is recommended; disabling an adapter
does not disable legitimate Wasm. Retained native DWARF is not Python lexical
or ROS-aware debugger acceptance.
