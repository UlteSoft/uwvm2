## Implemented SDK and examples

`wire.TransformStamped` represents the complete canonical timestamp, sequence,
parent/child frames, translation and xyzw quaternion. It checks the selected
backend before narrowing, rejects malformed frames, nonfinite scalars,
non-unit quaternions, incomplete/trailing input and overflow, and preserves
accepted Float64 bits. ROS1/ROS2 `Resource.lookup_transform` and
`Resource.broadcast_transform` perform one request through an already granted
owner. There is no hidden resize, replay, normalization or grant creation.

The active guide describes all fields and errors, ownership, builds, exact
numeric imports, independently selected TF grants, native library migration
and the remaining enabled-native acceptance. `08_transform_codec` is a pure
codec app. `08_transform_ros1` and `08_transform_ros2` have complete backend
ABI inventories and checked denial/cleanup paths. Their authorized source
branches have not yet passed a real native TF peer test. The corpus app and
independent C++ contract are bounded developer fixtures, not SDK authority.
