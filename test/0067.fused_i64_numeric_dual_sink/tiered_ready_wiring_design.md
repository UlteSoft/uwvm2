The current T0 INT admission and LLVM admission each still own a typed body walk. T2 checked-IR replay removal does not mean all tiered backends share one typed traversal. This successor only extends the genuine optional synchronous sink from the original INT walker for straight-line integer functions.

A future runtime admission factory must own the one original ring artifact and all native IR fragments, actual source/module/function identity and the exact compile profile. It must complete every Core3 semantic family with callbacks from that sole trusted first walker; unsupported legal native lowering must remain unavailable rather than invalid. It may not retry raw bytes or run pure validation first. Existing call/recursion/reference/table/GC/EH/control/OSR metadata must be genuine first-walk output, not guessed from the integer subset. At native materialization, all same-engine typed/raw/OSR callable aliases, exact prototypes/CC, actual loaded owned text ranges and unwind registrations must be verified before READY. No integer DATA artifact, target descriptor or optional native slice alone grants runtime publication, pause, restore or native debug authority.

The optional native subset has first-read i64 constants/local.get,18 i32 and18 i64 numeric events, and nineteen selected integer scalar memory operations. It still lacks native sink coverage for the other Core3 families, and its research call-info construction intentionally leaves raw-body trivial matcher unused. The test called start runs in the real ring while its optional native IR is unavailable, and all18 numeric functions have standalone actual native comparison. No all-backend single-walk, lazy readiness or performance claim is made.
