# Unpublished owned LLVM-full engine source proposal

This private native DATA factory uses a real `staged_compiler_module_owner`
minted only by `restoration_context`. It does not run guest code or initialize
expressions/segments/start. The world transaction supplies its actual newly
assigned dense module ID and one ordered public index/generation/body per local
function. Module graph word zero is the feature-policy revision, not a module ID.

Generation 1 must have no replacement bytes and borrows actual FINAL parser code
inside the source-owned byte image. A later generation owns its complete saved
body encoding, including local declarations and final end; it is parsed with the
existing feature-aware replacement code-section parser. The private validation
module uses those actual parsed local declarations. Each effective expression
is then validated and emitted once by the original LLVM-full fused walker, with
the actual generation, same rich continuation producer and profile17/ABI2.

The native target is selected before emission, and the genuine native EH ABI is
bound before real MCJIT finalization. All entries are obtained from actual LLVM
definitions owned by this engine, never from a same-name global lookup of an old
world. All four entries (ordinary typed/raw and restored typed/raw) must also
match exact function entries observed by this engine's uncommitted loaded-object
listener and fit its actual relocated text extent. The typed resume clone is a
real separate function, not only the raw wrapper's name. The only ELFv1 descriptor
or Thumb-tag normalization accepts the synchronous real native-loader callable
returned for that engine-owned defined Function; serialized or guest integers
never enter this path. This cold ownership check creates no ASM endpoint, CFI
proof, execution permit, runtime epoch or diagnostic publication.

No object cache, pending numeric plan, public entry/target, source seal,
runtime epoch, code range/permission, initialized flag or global selector is
created. Uncommitted event rows stay owned by the engine listener. The true
joint transaction still must authenticate the source/product/cache/feature
identity, every saved function generation and alias, all resources and roots,
actual old-world drain, dense module mapping, and only then issue actual new
publication/epoch/permission metadata. This factory alone is not restore.

`private_host_object_emission_scope` is constructible only by the genuine
nonmoving factory and is limited to its exact LLVM module during fused emission
and LLVM IR finalization. It restores compiler TLS on every return/exception.
Mutable object symbols use the existing architecture-correct literal/address
carrier path and never mutate LLVM's global object-symbol map. A wrong LLVM
module marks the attempt invalid and returns null before either `AddSymbol`.
The ordinary no-scope path is unchanged. Existing process-stable bridge/strict
float function registrations are preserved; this is not a claim that the entire
process symbol-name set is unchanged. These fixed function addresses contain no
clone-owned mutable DATA. No generated guest instruction reads compiler TLS.

The factory retains its genuine owner, typed parsed bodies, plans, stable target
allocation and LLVM context until native teardown. Listener destruction precedes
engine destruction, which precedes context/types/parsed body/source destruction.
It is serial; a future parallel factory must enter the same genuine record and
exact task LLVM module separately in every worker and join before owner release.

## Required real keeper tests (all currently unrun)

`scope_api.cc` compiles the actual exported construction restrictions and checks
ordinary/default/foreign/null selection without minting a scope from DATA.
The two modern WAT files exercise a real provider import, memory64/table64,
nondefaultable GC local and struct root across EH and a typed indirect call.
The actual original function `hot` has body bytes `00 41 25 0b`; a committed
generation 2 uses `00 41 2a 0b` and saved `expected` global 42. The malformed
same-ABI candidate `00 42 2a 0b` must fail genuine fused i64/i32 validation.
Those byte strings are body DATA, not prevalidated semantic certificates.

After true world-transaction integration, run original/gen2 native output37/42,
complete nested checkpoint restore, all sources/modules/body extents/roles and
cache/product mismatches, foreign/interior owner refusal, wrong LLVM module,
quota decline, real thrown parse/emission exception exit, and verify no scope
survives a failed attempt. Seed a live object name with the old module address;
check it before/after successful and failed private native compilation and prove
private module/global/memory addresses never replace it. Resolve every native
entry to the actual engine loaded object before publishing complete ranges and
ABI2 metadata at actual joint commit. Test both instruction/unwind policies,
header/module builds and little/big endian native/QEMU in the existing Linux
64GiB cgroup through the keeper. No Mac compilation or local VM tests occurred.

All C++ compilation, official WAT parsing, LLVM verifier/code generation,
native execution, unwind/CFI tests, performance tests and complete restore
qualification remain false. No production/public test hook was added to create
private compiler scopes or execute an unpublished engine.

## R2 successor and additional loaded-object tests

R1 is immutable. R2 preserves the same one-walk compiler/source generation
contract and independently rebases its small include/object-scope deltas onto
current ordinary and ROS source. The ordinary listener already has the bounded
readonly loaded-function check from T2; ROS receives that identical diagnostic
helper. Its presence neither admits arbitrary native PCs nor widens debugger
read/step authority.

The keeper must observe all four real entries in actual native loaded objects,
including the typed continuation clone, under both instruction/unwind policies.
For each candidate, a missing function definition, different-engine entry,
interior text address, zero entry, conflicting duplicate extent or text-overrun
must refuse private preparation before DATA is returned. Exercise the real
PPC64 ELFv1 callable descriptor and Thumb state tag where those native ABIs are
available; do not fabricate descriptor addresses from wire integers. Retaining
all four entries is not a successful unwind/CFI test. The world issuer still
has to bind actual aliases, code/CFI lifetime, resources and source/generation
identity at its true drain and publication transaction. All such executions and
cross-architecture tests are currently unrun.
