# Genuine fused artifact retention prototype

Status: **implemented test-owned prototype, source-only; official oracle/native/component results pending.** No production lazy representation or scheduler has been changed. This is an artifact-retention and lifetime proof, **not completion of int lazy or a performance qualification**.

Current ordinary lazy runtime accepts the module by a separate body-validation pass, constructs descriptors borrowing raw Wasm, and later invokes the full fused compiler again on demand. Removing that initial module check would incorrectly admit an uncalled invalid body. Core 3 [module validation](https://webassembly.github.io/spec/core/valid/modules.html#modules) includes every function and [instantiation](https://webassembly.github.io/spec/core/exec/modules.html#exec-instantiation) checks module validity before effects. The included invalid unused non-defaultable local makes this requirement observable to each real all-function producer.

`retained_artifacts.h` implements two private-constructor owned products. Both initial factories call actual all-function fused compilers on a genuine `full_source_instance`; callers cannot submit a ready flag, unchecked opstream, forged IR, or alternate decoder callback. The actual source owns its mapped bytes, original parsed recursive type context and initialized registry. Capturing this source compares the real selected owner/control block and published initializer serial. The source is declared before every compiled product and survives until those products' destructors finish.

The interpreter product retains the real full emitted opfunc streams and call-info metadata. Its deferred function view owns that product and selects only a checked local ordinal; its `program()` never receives or decodes a Wasm body. Repeated handoffs yield the same immutable source-backed emitted allocation. This shifts **all interpreter translation work and storage to startup**. It preserves a one-traversal artifact, but does not satisfy the desired production lazy startup/delay/register-ring contract. A production replacement still needs the initial core typed decoder to emit compact checked backend-neutral operations and control/operand/local/EH records, followed by demand lowering with no raw/LEB/semantic-stack replay.

The LLVM product retains the genuine emitted IR, its LLVMContext, local descriptors, and original source. A one-shot deferred handoff transfers those exact objects without a Wasm traversal. Its atomic claim prevents handing the same unique module/context pair to two consumers. This prototype verifies the transferred native IR and destruction ordering; it does **not** optimize, install an MCJIT engine, execute guest code, or demonstrate startup/peak-memory parity with user-requested LLVM lazy. Deferred native machine-code generation and its measured cost are a separate experiment.

Every operation here is cold and externally serialized native administration in a single-threaded fixture, after a genuine runtime drain. `source_cut::current` is a data/selection observation, not an execution generation lease or public management authorization. Production use with concurrent reset requires the actual runtime execution/publication lease and existing worker lifetime contract; this prototype must not be directly installed as that boundary. Retiring the selected runtime/source prevents new deferred handoffs, while existing immutable products safely retain the original source for data destruction/diagnostics. No API in this directory authorizes guest execution.

## Real component fixture

`artifact_retention.cc` loads exact original input bytes with the production fast_io loader into a genuinely nonmoving source owner, checks imports, calls the actual initializer with active segments deferred, and seals its real initialization phase. It supplies no synthetic runtime/code/type metadata and performs no preliminary pure body validation. All IO/string conversion and numeric printing use fast_io.

Each valid input has two functions and `_start` actually calls the new-syntax probe if subsequently executed by a runtime test: GC struct.new/get, try_table with a typed catch/throw payload, or memory64/table64 actual memory/table operations. This fixture inspects compiler products; it deliberately does not label those bodies executed. The invalid input's valid empty `_start` does not call its illegal non-defaultable local body. Each fused producer must nevertheless throw the exact invalid-parse/local-init diagnostic and mint no artifact.

For interpreter artifacts the component requests the first function four times, checks actual nonempty emitted stream identity, rejects an out-of-range ordinal, retains a function view through genuine reset, and checks that retired views/handoffs decline. LLVM components transfer the actual IR once, reject duplicate transfer, check original context identity and genuine LLVM verifier output before/after reset, and count actual function definitions. Both products must keep the real weak source lifetime alive after selection is retired and release it after the last product/view owner dies. The fixture counts actual factory invocations. It does not instrument individual bytecode reads or claim a measured decoder count; absence of decoder entrypoints in the handoff is a source property.

Arguments:

```
artifact_retention int|llvm accept|reject input.wasm
```

Use real matching SDK/objects in the shared SSH Linux 64 GiB cgroup. Interpreter-only can start with normal UWVM_USE_UWVM_INT/UWVM_DISABLE_JIT flags. Define UWVM2TEST_RUNNER_USE_LLVM_JIT for the LLVM component and link its real matching LLVM SDK/runtime. A LLVM-only component also defines UWVM_DISABLE_INT and UWVM2TEST_STRICT_NO_INTERPRETER. An unavailable backend exits 3 rather than reporting success. ROS has no production lazy modes; it shares this source/data proof without claiming to add one.

Before component execution, the keeper must use pinned current official `wasm-tools parse` on the original four WAT files, then validate those exact resulting bytes. All three valid inputs must pass; the invalid unused local must fail specifically for uninitialized non-defaultable local. Preserve all tool versions and raw diagnostics. A native/LLVM/formatter/allocator failure is not validation evidence. The original local-init reference is pinned to [official WebAssembly/spec 2e44bf79e68cc4fe689f43eea8e7d25b6fdfbce1](https://github.com/WebAssembly/spec/blob/2e44bf79e68cc4fe689f43eea8e7d25b6fdfbce1/test/core/local_init.wast); these four component probes are original reduced fixtures.
