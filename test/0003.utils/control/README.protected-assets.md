This is a source-only protected management asset foundation. No runtime management producer exists, so it cannot publish or restore a checkpoint. The registry has no public constructor/register API/global mutable instance; a numeric FD, pathname, identity, UUID, public stop ID, bool or read-only census report cannot mint its private transaction/token. Its only prospective friend is the real runtime management bridge.

A private entry owns one fast_io native_file and actual dev/ino/type identity, and tokens pin that same immutable control block/incarnation through pending writers/mappings. There are at most 256 entries /64 directories and 65536 census observations; incarnation exhaustion stays terminal zero. Only real Linux/Darwin identities are implemented. Windows/BSD and no-EH allocation remain explicit unqualified providers.

The first prospective admission is deliberately limited to no guest directory/preopen and no opaque native imports. Real producer input must enumerate all default/group WASI env fd_storage.opens and renumber_map, every directory stack entry, configured mount_dir_roots, stdio/inherited handles and every native/preloaded provider. Unknown/missing entries fail closed. Matching retained file aliases fail by actual identity, including hardlinks; a private file must also be newly created O_EXCL/0600, empty and nlink1. File metadata cannot prove creation or complete census.

Public inspect_census always reports management=manager_guard_unavailable, even for candidate_clean. Registration and retirement remain private. The future bridge must hold ONE actual closed-entry admission + host-operation drain/stopped-participant guard throughout census/new owner registration. Existing execution_domain.stop_and_drain cancels/waits for execution leases, so it cannot by itself stand in for a live checkpoint pause whose workers still own leases. The root/checkpoint manager integration is separate and pending. Guest FD/path mutation denial and protected loader/sealed input integration are also pending; this header adds no ordinary interpreter/JIT IR or hot memory guard.

The r2 foundation also checks the actual provider type for every file-list FD, so a directory cannot evade rejection by being placed in the wrong diagnostic array. Retirement consumes the final issued token under the real guard, requires all other writer/mapping pins to have ended, and closes the last native owner before its identity disappears. Private directories remain busy while any unpublished file entry exists. Nested transactions do not replace a live transaction. The prospective runtime bridge declaration uses extern "C++" global-module attachment; its future definition must use the same linkage specification. No runtime bridge is defined here.
