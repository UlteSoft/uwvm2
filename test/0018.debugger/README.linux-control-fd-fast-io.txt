Production scope: linux_control_fd.h only (one leaf per product), existing pidfd_open in adopt replaced by the existing exported FastIO system_call<SYS_pidfd_open,int> and two ancillary std::memcpy calls replaced by exported freestanding::my_memcpy. Every negative raw pidfd result is rejected before native_file adoption; the positive native errno is restored on failure to preserve the former libc syscall observable error. Successful nonnegative descriptors immediately transfer to existing native_file RAII. Peer credentials, launch-only FD>=3 admission, peer-live poll, endpoint sealing, stdio-alias rejection, CLOEXEC setup, command grammar and detach semantics are unchanged. The existing debugger syscall_noexcept declaration remains outside this narrowly scoped endpoint candidate; this proposal neither deletes it nor claims another remaining caller. No new vendor API or module bridge.

The finite actual GNU x86_64 LP64 fixture creates fresh unnamed SOCK_SEQPACKET|CLOEXEC|NONBLOCK sockets before fork. Actual child SO_PEERCRED points to the original parent; a live parent's independent SDK pidfd is compared, the actual product adopter seals/accepts the channel, flags are checked, then channel retirement and host-only post-drain unseal are followed by an independent stale-FD EBADF query. A second fresh child installs a 9-cell actual SDK seccomp filter only in that child: native architecture and non-x32 checks, exactly pidfd_open=>EMFILE, all other native operations allowed. SDK oracle first verifies real -1/EMFILE, then the real product adopter must reject, retain identical errno, close the supplied descriptor, and never publish sealed input. The parent/keeper is unfiltered. Fork/waitpid/socketpair/fcntl oracle aliases use real SDK types, noexcept asm linkage; I/O owners and output use FastIO. No controller, kernel, identity, runtime or credential test stubs are present.

Run both products x EH/noEH first as normal headers using real production includes (src, fast_io/include, bizwen/include, boost_unordered/include and actual LLVM headers if required by existing debugger headers). Module variant defines UWVM_TEST_DEBUG_CONTROL_FD_MODULE and must import fresh actual FastIO + utils.control + full uwvm2.uwvm.debugger graph/object closure, never preinclude FastIO headers or inject macro/stub modules. The SDK-only global fragment is the independent oracle. Compile/link/execute only through the sole Linux keeper's original 64GiB cgroup/ticket, with all child tasks tracked, bounded timeout and original supervisor retirement. No local compile, Mac execution or independent SSH lane.

Exit2 is actual provider/precondition/filter unavailability, never PASS; exit1 is a mismatch; only zero after both real children is a component pass. This fixture does not exercise full receive credential/SCM_RIGHTS/zero-record/truncation/replay/launcher-death or serve/detach behavior, and does not assert private pidfd leak counts. Those need separate actual transport/CLI qualification. Generic errno TLS bridge and other architectures/SDKs remain separately pending. This source change does not qualify the entire debugger or global filesystem migration.
