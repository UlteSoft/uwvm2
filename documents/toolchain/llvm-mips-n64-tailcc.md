# MIPS N64 R2 callee-pop TailCC

The [backend patch](patches/llvm-mips-n64-tailcc.patch) implements the private typed Wasm calling convention for qualified static Linux N64EL R2 providers. It builds on the bundled provider's existing MIPS call-range and asynchronous-CFI repairs. Exact source and archive hashes are recorded in the [native component receipt](../../test/0072.core3_codegen_cross/mips64el_tailcc_native.qualification.json). Other MIPS ABIs, compressed modes, R6, PIC, variadic/byval calls, interrupt handlers and EH-return functions remain outside this qualification.

The callee removes its aligned incoming argument area. A tail transfer adjusts the frame by the incoming/outgoing argument-area difference, reserves growing areas below saved registers and orders incoming stack loads before outgoing stores. Tail-return pseudos retain the adjustment until frame lowering. Normal TailCC calls restore the caller's stack too; calls with stack arguments require a stable frame pointer and disable reserved call frames. CFA and saved-register offsets follow the callee-pop protocol.

Generated typed functions and their call sites select the ABI together. The bundled provider advertises `LLVM_UWVM_ROS_MIPS_N64EL_R2_TAILCC=1`; independently qualified external backports use `UWVM_LLVM_MIPS_N64EL_R2_TAILCC_FIXED=1`. Aggregate parameters/results retain the established convention unless lowering supplied an explicit scalar result-address operand. C host entry and import boundaries keep their existing ABI. Module-owned definitions remain `dso_local`.

An empty or `generic` CPU name under QEMU becomes `mips64r2` for native MIPS64EL R2 target selection, matching the process's compile-time minimum ISA. Explicit CPU and cross-target AOT selections keep their existing behavior. The cache fingerprint adds `mips-n64el-r2-tailcc=callee-pop-v1` for this ABI and `producer-default` otherwise. It separates cached objects across ABI choices without disabling the cache.

The component receipt records 39 successful native executions across O1/O2/O3 and default/explicit tail-call policies, declaring 162 million tail edges; three expected compiler rejections; and 78 complete function extents from actual executed objects. Tests cover changing argument areas, indirect transfers, ordinary TailCC calls and exact floating-point/vector parameter bits. Another 39 executions perform real libgcc stack walks after those transfers. The finite fixture's two-JIT-frame expectation introduces no debugger depth limit.

The component used genuine revision .11 core archives with all 60 MIPS translation units rebuilt into five backend archives. Current ROS revision .12 requires its complete matching SDK; header/version checks must not be relaxed to reuse an older dependency. Wasm frontend execution, authenticated cache reuse, complete Core 3 coverage and hardware throughput require separate evidence.
