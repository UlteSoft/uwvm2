本次检查发现并修复的问题

1. Wasm if/loop 前缀 SSA 不能用当前基本块的调试副本替换。
   前缀仍可能在兄弟分支或合并块中使用，原先替换会破坏 dominance。
   保留 validator 的语义值；完成 CFG 后，仅重绑定被真实 identity 支配的使用。
   PHI 使用按其真实入边判断；兄弟分支和合并使用保持原值。
2. LLVM 局部值不能通过全局 metadata 保存未完成 CFG 的 identity。
   使用编译器私有 WeakTrackingVH 记录，正确处理 RAUW、删除和最终验证。
3. ConstantData 没有 intrusive use list。对 v128.const 调用 Value::uses()
   会触发 LLVM 断言。改为索引真实指令操作数，仍只修改已证明的使用。
4. v128 的物理值不能只依赖调试副本的 DWARF 位置。
   现在同时记录真实原始 SSA 结果；在后续快照 store 将位置变成 spill 前，
   保留实际运算结果的完整 128 位寄存器范围。独立消费 marker 仍证明活性。
   scalar 展开继续依赖完成后的 marker，避免将尚未完成的 i64 结果当作精确值。
5. numeric rebind 组件夹具的目标判断增加 Linux 条件，与实际 materializer 一致。
