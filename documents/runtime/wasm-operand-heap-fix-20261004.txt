Wasm operand preview 修复与验证（2026-10-05，V6）

两个本机仓库已同步：uwvm2、uwvm2-ros。
本次修复 cooperative Wasm opcode stop 的真实 typed operand/local materialization。
原 resumable restore ABI 与 native workspace 保留；ASM 调试仍限制在 Wasm 生成的上下文。

实现

1. observation-only 原来复用 32768 字节 native checkpoint workspace。
   1000 个 locals 加两个 operands 就可能被拒绝，即使 Wasm 合法且元数据预算足够。
   现在使用实际 debug execution scope 所有的独立堆缓冲区。
   每个实际函数调用只分配一次，最终大小由编译器确定：
   2 * local_count + 16 * max_typed_slots，最小 1 字节。
   两组 local flags 和 typed values 分开保存；嵌套 buffer 地址稳定。
   所有已验证 opcode site 完成后，编译器把最终 extent 写入 allocation CallInst 常量，
   再优化、封存、发射 object。没有 runtime realloc，也不接受 guest 提供 extent。
   return、typed tail、host tail、frame-exiting EH 在 activation leave 前释放 top buffer。
   allocation/release 仅是私有 storage bridge，不增加 query/capture/restore/PC 权限。
   所有权不依赖诊断 ledger，identity quota 耗尽仍允许 guest 正常执行和清理。

2. 普通执行入口按 admission 下不可变的配置选择 template<bool Debug> helper。
   false specialization 不构造 debug scope、不安装新 arena TLS、不读取该 scope 的 participant TLS。
   helper 强制 inline，public entry 保持 noinline，保留实际 native CFA 边界和 admission。
   DBG 关闭时，Wasm 生成代码没有新增 packet stores、materialization、arena allocate/release。
   host entry 仍有一次模式选择，原有其它 host/table debug-control 检查仍存在。
   因此本次证明生成代码没有新增预览开销；没有宣称整进程所有入口绝对零开销。

3. 补上关闭 pause domain 后的执行生命周期。
   participant 的 enter() 在 close 后返回空，但已生成 observer 代码仍需要真实 packet storage。
   现在先建立实际 scope 的 arena owner，再尝试 participant admission。
   关闭后的调用允许继续执行；嵌套 raw entry 借用外层 arena，不替换或清除外层所有者。
   destructor 独立清理 arena TLS。关闭后的 preview 明确不可用，不伪造暂停或注册身份。
   旧 V5 runtime 的 full/raw 入口在相同测试中完成 native publication 后失败；V6 正常返回。

observer cache policy12 -> 13，防止旧 object 混用。
resumable cache policy17、native resume ABI2、32768 字节 workspace 及原 provenance 检查未改。
source/generation/pause/root 检查保留。新增 C++ 诊断与测试输出使用 fast_io。
ROS 保留 full interpreter/full LLVM JIT 的模式范围与真实 LLVM .10 pin。

界限

- activation identity 仍最多64帧，超出后 preview 明确不可用，合法 guest 仍能执行和清理。
- observer 元数据仍受配置预算（默认1048576 slots/frame）、地址宽度、可用内存限制。
- 准确 typed 预览发生在 cooperative Wasm opcode stop。本次没有实现 arbitrary ASM PC 的
  register/memory map，不承诺任何 native 指令中途都能重建 Wasm data stack。
- 本次没有增加完整检查点恢复或外部IO回滚，不允许 ASM dbg 越出 Wasm 上下文调试 VM。
- QEMU DATA 组件、Core3 smoke、3条指令样例不等价于全部架构、全部特性或所有性能保证。
