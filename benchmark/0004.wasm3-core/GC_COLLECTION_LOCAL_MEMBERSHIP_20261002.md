Source implementation only; no native, VM, sanitizer, assembly or performance pass is asserted. The initial gate is **UWVM_EXPERIMENTAL_COLLECTION_LOCAL_MEMBERSHIP==1**. Undefined, 0 and 2 keep the original path. It is independent of the six compact/numeric experiments, metadata, SET32 and shared-status dispatch.

## Exact change and authority

In each existing collector branch, after actual canonical strong-pin/cohort/bridge/exception-registry checks, the new private helper qualifies the already stopped canonical cohort. For tracked slab reservation, closing or epoch-exhaustion failure it declines only the optimization and keeps the old global-stripe route and its original late error precedence. No early error is introduced. Compact-object decode remains first in the compact branch.

For ordinary aggregate tokens, the qualified helper probes each actual pin's existing checked_local_object. That routine compares the untrusted token as a KEY and acquires the release-published local bucket head; it never converts the guest token into a native object address. The native member must have exact owner identity equal to that same pin, plus existing kind/token checks. Layout, shape and canonical type equality cannot authorize an owner or source. Null, forged, stale, wrong-kind or outside-cohort keys fail rather than silently enlarging the root snapshot.

The boolean is not an execution permission. All original public collector requirements remain: **actual complete admission and pause**, all mutators/readers stopped, every enrolled live store in the canonical strong-pin cohort, exact complete roots, and no unpublished allocation in flight. reserved_slots==0 covers only the tracked numeric allocator; it cannot prove that byte-array publishers or unknown native actors are absent. The managed runtime obtains its original exclusive admission/serial before calling the collector, and polls before allocation. A privileged native caller must obey the same contract. A TLS flag, active-count observation, LLVM-full mode or one-module assumption is insufficient.

The original cohort lock excludes enrollment/unlink while the pins exclude store destruction. Local publication uses release CAS before guest exposure, and the allocating actor's real shared entry covers reserve/construction/publication. Peers and management retain their original leases. No callback/poll is added in the publication gap. The helper borrows only for the current collection, allocates nothing and saves no pointer across epoch, admission or pause release. It neither weak-promotes foreign owners nor bypasses the caller's canonical membership checks.

## Error, graph and sweep invariants

Full aggregate/exception-graph preflight still runs in its original order before any reclamation. Every real reference is still checked. Exception registry identities, registered native values, unknown external owners, foreign leases, root census, mark work allocation, OOM precedence, epoch invalidation and sweep are unchanged. Invalid late/unreachable references must still yield zero reclamation and unchanged epochs/tokens.

The original sweep unlinks each dead node from the local bucket with release semantics BEFORE removing it from the global index and destroying it. This matters: lease-prune lookups can run after an earlier object/store was swept. The candidate relies on that original ordering and must not replace it with only an end-of-sweep rebuild. Mutator synchronization, canonical layout checks and ordinary checked_object/checked_foreign_object are untouched.

No object/store field, public allocator API, representation, generated bridge ABI, validator pass or interpreter path changes. The private .inc is consumed inside the existing gc_object_store definition, not a separately exported public module. Its cache context adds only the exact1 key gc-collection-local-membership=closed-canonical-local-v1. Actual native runtime/main/host TU definitions must agree; this key does not itself prove source/build identity.
